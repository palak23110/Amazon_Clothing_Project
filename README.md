# Amazon Clothing & Accessories Data Analytics

## Objective:
Analyze Amazon clothing & accessories data to uncover patterns in pricing, ratings, and product categories.

## Dataset:
Kaggle – Amazon E-Commerce Product and Review Dataset (2023)

## Methods:
- Data Preprocessing: Handling missing values, cleaning, outlier removal.
- EDA: Histograms, bar charts, scatter plots, correlation heatmaps.
- Statistical Analysis: Pearson correlation, hypothesis testing.
- Clustering: K-Means clustering to identify product segments.

## Key Insights:
- Prices mostly cluster at lower end, few high value premium items.
- Weak correlation between price and ratings.
- Right skewed distributions in price and review counts.
- K-Means clustering identified affordable, mid range and premium segments.

## Conclusion:
Analysis from EDA and clustering can help improve product suggestions and inventory planning, also extra data might show new trends.
